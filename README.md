# Отель «Мироген» — раннее бронирование

Коммерческий одностраничный сайт для проверки условий раннего бронирования в отеле «Мироген» в Лермонтово. Сценарий страницы: даты → состав семьи → категория номера → питание → контакт → структурированное сообщение администратору.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Production-проверки:

```bash
npm run build
npm run lint
npm test
```

## Структура

- `app/page.tsx` — интерфейс страницы, форма и сценарии заявки.
- `app/data.ts` — единый объект с оффером, категориями номеров, питанием, FAQ и контактами.
- `app/globals.css` — визуальная система, адаптивные состояния и reduced motion.
- `public/images/official/` — локальные WebP-изображения из официальной фотогалереи и разделов отеля.
- `CONTENT_SOURCES.md` — URLs, дата проверки и назначение использованных фактов и изображений.

## Интеграция формы

Сейчас серверная отправка не имитируется. После заполнения формы сайт формирует готовое сообщение и предлагает открыть WhatsApp, отправить e-mail, скопировать текст или позвонить по телефону отеля.

Для подключения CRM или серверного endpoint замените обработчик `handleSubmit` в `app/page.tsx`, сохранив поля заявки и UTM-метки. До этого администратор получает запрос через выбранный пользователем канал.

## Публикация

- Репозиторий: https://github.com/ya-yura/mirogen-early-booking-landing-20260813
- Живое демо: https://ya-yura.github.io/mirogen-early-booking-landing-20260813/

Workflow `.github/workflows/pages.yml` собирает статическую версию с базовым путём репозитория и публикует её в GitHub Pages после push в `main`. Скрипт `scripts/export-pages.mjs` упаковывает HTML динамичной интерактивной страницы вместе с production-ассетами.

Страница подготовлена под GitHub Pages и Sites-hosting. Если сайт будет переноситься на домен отеля, перед релизом нужно подтвердить право на использование локально сохранённых фотографий.

## Существенные допущения

- На официальных страницах срок раннего бронирования указан неодинаково. В интерфейсе оставлена нейтральная формулировка, а поле `offer.deadline` в `app/data.ts` подготовлено для единого подтверждённого значения.
- Тарифы и наличие номеров не показываются: они зависят от дат и должны быть подтверждены администратором.
- Фактический адрес, телефон, e-mail, WhatsApp, категории номеров, питание, услуги и правила заезда перенесены из официальных материалов, перечисленных в `CONTENT_SOURCES.md`.
